# Logit Conditioning Layer
* **Responsibility**: Intercepts the raw outputs of the visual model and adjusts the prediction distribution using geographic contexts without destroying the underlying embedding logic.
* **Technical Stack**: PyTorch, Nvidia CUDA / Apple Silicon MPS hardware acceleration.

## Operation: `apply_geographic_prior`
* **Description**: Takes the unconditioned output tensor ($z_{\text{raw}}$) from the visual classification head and mathematically conditions it before passing it to the Softmax function. The operation executes an additive log-space shift using a tunable scalar hyperparameter $\gamma$ (Gamma) and an underflow safety factor $\epsilon$:
  $$z_{\text{conditioned}} = z_{\text{raw}} + \gamma \cdot \log(G + \epsilon)$$
  This operation forces visually similar but geographically impossible species downward in score, allowing the correct native look-alike class to naturally shift to the top prediction spot. A Softmax function is then run on $z_{\text{conditioned}}$ to yield final probabilities.
* **Inputs**:
  * `raw_logits` (Tensor of shape `[M, N]`): Unconditioned raw logits ($z_{\text{raw}}$) for $M$ detected objects across $N$ species classes.
  * `spatial_prior_mask` (Tensor of shape `[N]`): The geographic prior vector $G$ generated by the Prior Service.
* **Outputs**:
  * `final_species_predictions` (JSON / Dictionary structure): The finalized, geographically conditioned taxonomic payload containing the highly accurate species identifications along with corrected confidence percentages.
